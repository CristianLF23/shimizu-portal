# SHIMIZU · 清水

Assinatura baseada nos contornos originais da fonte Yuji Syuku, por Yuji Project / Kinuta Font Factory, SIL Open Font License 1.1.

Fonte oficial: https://github.com/Kinutafontfactory/Yuji
Licença preservada: ../fonts/yuji-syuku-OFL.txt
Caracteres: 清 (U+6E05) e 水 (U+6C34).

shimizu-signature.svg utiliza currentColor. As versões ivory, ink e copper têm cores fixas e fundo transparente. favicon.svg usa 清 como monograma sobre vermelho.

A composição foi criada para o site a partir da capa fornecida pelo usuário. Os glifos não são uma reprodução exata da assinatura da artista na capa.
